# Lesson 01.5 workbook — build the filters

The run-through showed the filters working. This workbook builds them.

## Exercises

1. Change one kernel coefficient and predict the new correlation.
2. Write `correlate_image` and match OpenCV's `filter2D` for two border rules.
3. Write `convolve_image` from one flip and one call.
4. Design a kernel and explain why it works.

Each exercise stops with an error until the code above it is written. Figures
appear only after the checks pass.
